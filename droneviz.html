DroneViz

DroneViz is a compact, low-SWaP counter-UAS detection system built for rapid deployment. Housed in a lightweight, self-contained pod, it combines optical sensing with onboard edge processing to deliver real-time drone detection and tracking without external infrastructure. Designed for integration on airships, unmanned aircraft, and mobile platforms, DroneViz provides awareness for security and event protection operations.
