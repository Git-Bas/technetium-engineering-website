# Technetium Engineering Website

Static one-page website for Technetium Engineering.

## Deploy
Upload the contents of this folder to GitHub Pages, Cloudflare Pages, Netlify, or any static host.

## Main files
- `index.html` — website content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, reveal animations, contact mailto, and animated background
- `assets/` — images, logos, video, and favicon

## Contact form
The form is static and opens the visitor's email client with a pre-filled email to `hello@technetiumengineering.com`.
